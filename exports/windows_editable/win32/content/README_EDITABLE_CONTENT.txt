English Passport editable content

Edit only the JSON files in content/data.

Editable files:
- school_gate_quiz.json
- classroom_read_listen_click.json
- classroom_language_quiz.json
- meet_choose_question.json
- meet_politeness_fix.json
- my_school_card_label_classroom.json

You can keep using internal assets with res:// paths.
For new external assets, put files in content/images or content/audio and reference them from JSON like:
- content://images/my_new_image.png
- content://audio/my_new_audio.ogg

Recommended audio formats: .ogg, .mp3, .wav
Recommended image formats: .png, .jpg, .webp

Do not rename the content folder. It must stay next to the executable.
