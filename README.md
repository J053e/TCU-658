# TCU-658

Base de proyecto para el juego educativo **English Passport: Here I Am!**, orientado a estudiantes de secundaria que están aprendiendo inglés.

## Stack

- **Motor:** Godot 4.x
- **Lenguaje:** GDScript
- **Objetivo:** base portable para Windows.

## Cómo abrir

1. Instalar Godot 4.x
2. Abrir Godot y seleccionar **Import**.
3. Eligir esta carpeta: `C:\Users\JosePC\Desktop\TCU\TCU-658`.
4. Ejecutar la escena principal.
